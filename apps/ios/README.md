# TravelMate iOS

This directory contains a SwiftUI foundation for the TravelMate iOS application.

## Notes

- The project is intentionally scaffolded as a native SwiftUI app foundation.
- It follows the expected app structure for future authentication, profile, trip, chat, and payments flows.
- Open this folder in Xcode to develop the full native app experience.
- Secure networking, Apple authentication, and app-store compliant billing must be added before production deployment.
